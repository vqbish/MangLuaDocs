Enums and generics ​

Enums are immutable named collections of values ​

lua
enum Element { Fire, Water = 5, Air }

assert(Element.Fire == 0)
assert(Element.Water == 5)
assert(Element.Air == 6)
assert(Element.name(5) == "Water")
assert(#Element == 3)

Members are ordinary underlying values, not objects carrying .name. Use Element.name(value) for reverse lookup. typeof(Element.Fire) therefore does not promise the enum type name. Element.Fire is a number.

ExpressionResult
Element.name(value)First registered member name for the value, or nil
Element.value(name)Value for a name, or nil
Element.has(name)Whether the name exists
Element.names()Ordered list of names
Element.values()Ordered list of values
#ElementNumber of entries
kindof(Element)"enum"
isenum(Element)true

Unknown direct member reads and assignments raise at runtime. The strict analyzer also reports unknown members and immutable-member writes. In runtime-checked execution those operations remain catchable:

lua
assert(not pcall(function() return Element.Missing end))
assert(not pcall(function() Element.Fire = 1 end))

Generic classes ​

lua
class Box<T>
    private item = nil

    public function init(value)
        self.item = value
    end

    public function Get()
        return self.item
    end

    public function Argument()
        return typeargs(self).T
    end
end

local box = new Box<Element>(Element.Water)
assert(box:Get() == 5)
assert(box:Argument() == Element)
assert(typeof(box) == "Box<Element>")
assert(instanceof(box, Box))

Specialization is performed by the MLua runtime. Repeated specialization with the same type arguments is cached.

Generic functions and component calls ​

lua
local function AddComponent<T : Component>(target: object): object
    return target:AddComponent<T>()
end

This function requires the game to expose Component and the component API used by its caller. The type argument is forwarded to the managed operation. A generic parameter used as a managed type must resolve to an exposed type or class.

The runtime handles constrained forwarding and AddComponent type inference directly.
