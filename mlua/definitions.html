Definitions and Conditional Compilation ​

Definitions are compile-time flags evaluated by MLua before your chunk is compiled. They let you easily turn features on or off, support different game versions, or separate debug code from release builds.

Declaring Values ​

You can define flags right at the top of your Lua files using #define:

lua
#define SHOW_COUNTER true
#define LIMIT 10
#define MOD_NAME "ExampleMod"

#ifdef SHOW_COUNTER
print("Counter feature is enabled!")
#endif

Writing #define NAME by itself defines NAME as true. You can also assign booleans, numbers, or double-quoted strings. Note that directive names are case-sensitive.

Available Directives ​

DirectiveWhat it does
#define NAME valueDefines a flag or value in the active branch
#undef NAMERemoves a previously defined flag
#ifdef NAMEChecks if a flag has been defined
#ifndef NAMEChecks if a flag has not been defined
#if NAMEChecks if a definition evaluates to true
#ifnot NAMEChecks if a definition evaluates to false
#elif NAME, #elseif NAMEAlternative conditional branch
#elseFallback branch if previous conditions were false
#endif, #endCloses the conditional block

Conditions take a flag name, optionally prefixed by ! or not. This is a clean conditional compilation tool - arithmetic expressions like #if VERSION >= 2 are not supported.

lua
#define FEATURE false

#ifdef FEATURE
print("FEATURE is defined")
#endif

#if FEATURE
print("This line will not be compiled")
#else
print("FEATURE is disabled")
#endif

#undef FEATURE

Lines inside inactive branches are simply skipped, preserving line numbering for accurate error messages.

Flags Provided by the Game ​

Games can also inject global runtime flags into your environment through the DEFINE table. You can check for them using defined(name):

lua
if defined("GAME_VERSION") then
    print("Running under game version:", DEFINE["GAME_VERSION"])
end
