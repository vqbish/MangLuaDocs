MLua Language Reference ​

MLua is a strict superset of Lua 5.4, so every valid Lua 5.4 chunk is valid MLua without modification. All standard Lua behaviour is preserved exactly: comments, strings, numbers, operators, control flow, closures, varargs, multiple returns, metatables, coroutines, and goto. Everything described on this page is either inherited directly from Lua or is a purely additive MLua extension.

This reference assumes familiarity with at least one statically typed language such as C#, TypeScript, or Java. Lua-specific concepts such as metatables and coroutines are not explained here - see the Lua Reference Manual for those.

Chunks ​

A chunk is a sequence of statements. Semicolons between statements are never required - a bare ; is accepted as an empty statement.

lua
local message = "hello"
print(message)

Comments ​

Line and block comments follow standard Lua syntax:

lua
-- Line comment

--[[ Block comment
     spanning multiple lines ]]

Values ​

MLua shares Lua's eight value types:

TypeDescription
nilThe absence of a value
booleantrue or false
numberInteger or float subtype
stringImmutable byte sequence
tableAssociative array and the basis for all objects
functionFirst-class callable value
userdataHost-managed object (e.g. a Unity component)
threadCoroutine

MLua introduces no new runtime value kinds. Classes, interfaces, and enums are a compile-time layer built on top of tables and userdata.

Variables ​

Local, global, constant, and to-be-closed variables all follow Lua 5.4 syntax:

lua
local count = 0
local a, b, c = 1, 2       -- c is nil
local frozen <const> = 10  -- compile-time constant
local handle <close> = open() -- closed automatically when the scope exits
globalValue = 1             -- global assignment (no 'local' keyword)

Any local variable may carry an optional type annotation. The compiler verifies it before the chunk runs:

lua
local speed: number = 90
local owner: Player = FindPlayer()

→ See Types and Annotations for the full type system, inference rules, and assignability.

Operators ​

MLua keeps all Lua 5.4 operators and adds type queries and safe member access:

GroupOperators
Arithmetic+ - * / // % ^ unary -
Bitwise& | ~ << >> unary ~
Comparison== ~= < <= > >=
Logicaland or not
String / size.. #
Type helper callsinstanceof(v, C) implements(v, I) typeof(v) kindof(v) classof(v)
Safe access?. ??

Precedence follows Lua 5.4. Type queries use ordinary function calls, not infix operators. Compound assignments (+=, -=, *=, …) are also supported.

lua
local label = enemy?.name ?? "unknown" -- nil-safe access with fallback
local isEnemy = instanceof(value, Enemy)  -- runtime type check
local typeName = typeof(value)           -- returns the type name as a string

Control Flow ​

All Lua 5.4 control structures are available. MLua adds continue for skipping to the next loop iteration:

lua
-- Conditional
if value > 10 then
    print("high")
elseif value > 0 then
    print("low")
else
    print("zero")
end

-- While loop
while active do
    step()
end

-- Repeat-until
repeat
    step()
until done

-- Numeric for with continue
for index = 1, 10, 2 do
    if index == 5 then continue end
    print(index)
end

-- Generic for
for key, value in pairs(source) do
    print(key, value)
end

-- Explicit scope block
do
    local scoped = 1
end

Loop controls:

StatementBehaviour
breakExits the innermost loop
continueSkips to the next iteration (MLua only)
goto label / ::label::Unconditional jump, as in Lua 5.4

Functions ​

Functions are first-class values and support all Lua 5.4 declaration forms:

lua
-- Local named function
local function add(a, b)
    return a + b
end

-- Global function with varargs
function Global(a, ...)
    return a, select("#", ...)
end

-- Function expression
local handler = function(event) end

-- Method with implicit self
local target = {}
function target:Method(value)
    return self, value
end

Parameters and return types accept optional annotations, checked by the compiler before the chunk runs:

lua
local function Distance(from: Vector3, to: Vector3): number
    return (to - from).magnitude
end

→ See Types and Annotations for annotating functions, overloads, and generics.
