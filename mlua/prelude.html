Prelude ​

The prelude is the set of globals available to every chunk before it runs. The VM opens selected Lua 5.4 libraries: base, table, string, math, coroutine and utf8. It does not open the entire standard library. The tables below show common functions, not every member.

os, io, package, debug, load, loadfile, loadstring and dofile are removed from the native environment. The integration installs a restricted require for registered source modules. It is not filesystem or native-library access.

Type and class helpers ​

FunctionDescription

kindof(value)Kind of the value: class, interface, enum, table, and so on.
classof(value)The class table, or nil.
instanceof(value, class)Whether the value derives from the given class.
implements(value, interface)Whether the value satisfies the registered interface.
isenum(value)Whether the value is an enum.
typeargs(value)The runtime type arguments of a generic instance.
typecheck(value, expected, label)Assert that a value has the expected type.
super(self, class, name, ...)Invoke the base implementation of name.

Managed modules ​

Managed libraries must be registered and loaded in the script environment. Mang.Reflection is registered by the managed script wrapper. Mang.Patches requires a configured patcher.

ModuleContents
Mang.Patchesinstalled unpatchOwner unpatchTarget unpatchAll
Mang.Reflectiontypes hasType members staticMembers constructible patchTargets resolvePatch
lua
give Mang.Patches
give Mang.Reflection

print(Mang.Patches.installed())
print(Mang.Reflection.hasType("UnityEngine.Transform"))

See Patching for the patch attributes and the frame, and Class injection for injecting new managed types.
