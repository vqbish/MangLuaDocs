Classes and Interfaces ​

Classes let you bundle fields and methods into clean, reusable types. Interfaces let you define contracts that those classes must follow. Together, they give MLua a full-featured object-oriented programming system - compiled down to fast tables and userdata at runtime, with static type checking before your code ever runs.

If you've used C#, Java, or TypeScript, you'll feel right at home. The main differences in MLua are that self is written explicitly in methods, and super calls use a simple helper function.

Declaring a Class ​

Here is a straightforward counter class:

lua
class Counter
    public value: number = 0

    public function Increment(): number
        self.value = self.value + 1
        return self.value
    end
end

Declaring a class creates a new named type. You can define it globally or inside a namespace. Close the class body with end. Inside any method, self refers to the current instance.

Members ​

You can define fields, methods, constructors, and static members in whatever combination you need:

Member KindExample SyntaxWhat it does
Fieldpublic value: number = 0Instance variable initialized when an object is created
Methodpublic function Name(args): ReturnType ... endFunction callable on instances with obj:Name()
Constructorpublic function init(args) ... endInitializes a new instance when created
Static fieldpublic static count: number = 0Belongs to the class itself, accessed via Counter.count
Static methodpublic static function Create(): Counter ... endCalled directly on the class: Counter.Create()

Access Modifiers ​

Every member has a visibility level to help you keep your code clean and prevent bugs:

ModifierWho can see it
publicAnyone, from anywhere. This is the default if omitted.
protectedOnly the class that declared it and its subclasses.
privateOnly the specific class that declared it.

Inheritance ​

A class inherits from a parent class using : BaseName:

lua
class Base
    public virtual function Value(): number
        return 1
    end
end

class Child : Base
    public override function Value(): number
        return super(self, Child, "Value") + 1
    end
end

Inheritance keywords:

KeywordWhat it does
overrideRequired whenever you replace an inherited method from a base class.
finalPrevents child classes from overriding this method further down.
abstractDeclares a method signature without a body - must be implemented by subclasses.
abstract classMarks a class that cannot be directly instantiated with new.

To call the parent class's version of a method, use super(self, CurrentClass, "MethodName", args...).

Abstract Classes ​

Abstract classes let you define a template for other classes to build upon:

lua
abstract class Shape
    public abstract function Area(): number
end

class Circle : Shape
    public radius: number = 1

    public override function Area(): number
        return 3.14159 * self.radius * self.radius
    end
end

Creating Instances ​

MLua gives you three interchangeable ways to create an instance and call its constructor init:

lua
local a = Counter.new()   -- lowercase .new()
local b = Counter.New()   -- uppercase .New()
local c = new Counter()   -- new keyword, just like in C# or Java

All arguments are automatically forwarded to your init method:

lua
class Person
    private name: string = ""

    public function init(name: string)
        self.name = name
    end

    public function GetName(): string
        return self.name
    end
end

local person = new Person("PlayerOne")
print(person:GetName()) -- "PlayerOne"

If a class doesn't declare an init method, instances are created with all fields set to their declared defaults.

Interfaces ​

Interfaces declare a contract of methods that implementing classes promise to provide. Interfaces hold no state - they contain no fields and no implementation code.

Short form - great when you just need to list member names:

lua
interface IValue(Value)
interface IDrink(MakeDrink, Refill)

Block form - when you want to specify full parameter and return types:

lua
interface IShape
    public function Area(): number
    public function Scale(factor: number)
end

Implementing an interface uses the implements keyword:

lua
class CoffeeCup : Person
    implements IDrink
    public function MakeDrink(): string
        return "espresso"
    end

    public function Refill()
        print("Refilled!")
    end
end

A class can implement as many interfaces as you want: implements IDrink, IValue, IShape. If you forget to implement any declared method, the compiler will tell you immediately.

Complete Example ​

Here is how abstract base classes and interfaces fit together in practice:

lua
abstract class Entity implements IShape
    public abstract function Area(): number
    public name: string = "entity"
end

class Box : Entity
    public width: number = 1
    public height: number = 1

    public override function Area(): number
        return self.width * self.height
    end
end

local box = new Box()
box.width = 4
box.height = 3
print("Area:", box:Area()) -- 12
