Типы и аннотации ​

Аннотации типов не являются обязательными. Они сообщают компилятору ожидаемый тип значения и проверяются до запуска вашего скрипта.

Где разрешены аннотации ​

lua
local count: number = 0

local function Scale(value: number, factor: number): number
	return value * factor
end

function Attach(target: object): object
	return target
end

class Player
	public health: number = 100
	private name: string = ""

	public function Heal(amount: number): number
		self.health = self.health + amount
		return self.health
	end
end

Встроенные имена типов ​

ИмяЗначение
anyЛюбое значение. Совместимо со всеми типами в обе стороны.
objectКорневой тип. Любое значение приводимо к нему.
nilЗначение nil. Присваивается любой аннотации.
booleantrue или false.
numberЦелое число или число с плавающей точкой.
stringТекстовая строка.
tableТаблицы Lua. Экземпляры классов MLua используют userdata.
functionЛюбая вызываемая сущность.
userdataНативный или управляемый дескриптор.
voidОтсутствие возвращаемого значения.

Имя любого объявленного класса, интерфейса или enum также является типом. Составные имена разрешаются через пространства имён, например UnityEngine.Vector3.

Совместимость и присваивание ​

  • any совместим с любым типом данных.
  • nil можно присвоить переменной с любой аннотацией.
  • object принимает любое значение, включая литералы таблиц.
  • Класс совместим со своими базовыми классами и интерфейсами, которые он реализует.
  • Параметры типов взаимно совместимы внутри области видимости своего дженерика.
  • Во всех остальных случаях типы должны совпадать по категории и имени.
lua
local function Accept(value: object) end

Accept(1)
Accept("text")
Accept({})
Accept(nil)

Вывод типов ​

Если у локальной переменной указана аннотация типа, а вызываемый метод является универсальным, аннотация помогает определить целевой тип:

lua
local function Attach(cube: GameObject): CubeRotator
    local rotator: CubeRotator = cube:AddComponent()
    local resolved: CubeRotator = cube:GetComponent()
    return resolved
end

Здесь cube - параметр функции. CubeRotator должен быть объявленным классом компонента. Оба вызова получают CubeRotator как запрошенный тип, поэтому явный аргумент дженерика можно опустить.

Запросы типов ​

lua
local isPlayer = instanceof(value, Player)
local canDrink = implements(value, IDrink)
local typeName = typeof(value)
local kindName = kindof(value)
local classTable = classof(value)
ФункцияРезультат
instanceoftrue, если значение является экземпляром класса или его наследника
implementstrue, если класс значения реализует указанный интерфейс
typeofИмя объявленного типа в виде строки
kindofКатегория типа: class, interface, enum, table, number и т.д.
classofТаблица самого класса или nil для обычных значений
