Работа с Unity и игровым API ​

Когда вы создаёте моды на MLua, вы пишете не изолированные скрипты - вам открыт полный доступ к движку Unity и внутренним системам самой игры. Вы можете спавнить объекты на сцене, перемещать их, работать с физикой, управлять камерой и вызывать игровые функции напрямую из Lua.

Подключение Unity ​

Чтобы использовать типы Unity в своём скрипте, просто запросите пространство имён с помощью give:

lua
give UnityEngine

local player = GameObject.Find("Player")
if player ~= nil then
    print("Игрок найден на позиции: " .. tostring(player.transform.position))
end

После этого стандартные типы Unity, такие как GameObject, Transform, Vector3, Time и Mathf, становятся полностью доступны.

Работа с игровыми объектами (GameObject) ​

Находить, создавать и изменять объекты в мире можно очень просто:

lua
give UnityEngine

-- Найти существующий объект на сцене по имени
local boss = GameObject.Find("BossEnemy")

-- Найти объект по тегу
local spawnPoint = GameObject.FindWithTag("Respawn")

-- Создать новый примитивный объект в мире
local cube = GameObject.CreatePrimitive(PrimitiveType.Cube)
cube.name = "MyModCube"

-- Переместить его в нужные координаты
cube.transform.position = Vector3(0, 10, 0)

Получение и добавление компонентов ​

В Unity каждый GameObject состоит из компонентов. Вы можете искать существующие компоненты на объекте или прикреплять новые:

lua
give UnityEngine

local light = cube:GetComponent<Light>()
if light == nil then
    -- Добавляем компонент, если его ещё нет
    light = cube:AddComponent<Light>()
end

-- Настраиваем свойства компонента
light.color = Color.red
light.intensity = 5.0

Вы также можете прикреплять свои собственные классы MLua, помеченные атрибутом @[Component] - подробнее об этом читайте в разделе Инъекция классов в Unity.

Чтение и запись свойств ​

Свойства и поля объектов Unity читаются и меняются как обычные поля таблиц в Lua:

lua
give UnityEngine

local player = GameObject.Find("Player")
local transform = player.transform

-- Читаем текущую позицию
local currentPos = transform.position
print("Координаты:", currentPos.x, currentPos.y, currentPos.z)

-- Сдвигаем игрока вперёд
transform.position = currentPos + Vector3(0, 0, 5)

-- Получаем дельту времени кадра
local delta = Time.deltaTime

Вызов методов ​

Методы компонентов и объектов Unity вызываются через стандартное двоеточие Lua :Method():

lua
give UnityEngine

local rb = player:GetComponent<Rigidbody>()
if rb ~= nil then
    -- Вызываем метод экземпляра
    rb:AddForce(Vector3.up * 10, ForceMode.Impulse)
end

-- Вызываем статический метод
local dist = Vector3.Distance(player.transform.position, cube.transform.position)
print("Дистанция до куба:", dist)

Векторы и математика ​

Векторы и математические функции Unity работают прямо из коробки:

lua
give UnityEngine

-- Создаём векторы
local spawn = Vector3(10, 0, 10)
local offset = Vector3(0, 2, 0)
local target = spawn + offset

-- Операции с векторами
local direction = (target - spawn).normalized
local distance = Vector3.Distance(spawn, target)

-- Цвета
local highlight = Color(1.0, 0.5, 0.0, 1.0)

Списки и коллекции C# ​

Когда игра возвращает список (List) или массив C#, вы можете узнать его длину и перебрать элементы через методы коллекции:

lua
local inventory = player:GetComponent<Inventory>()
local items = inventory.Items

-- Количество предметов
print("Количество предметов в инвентаре:", items.Count)

-- Перебор элементов по индексу
for i = 0, items.Count - 1 do
    local item = items:Get(i)
    print("Предмет:", item.name)
end

Собственные пространства имён игры ​

Помимо движка Unity, игры часто открывают собственные пространства имён с геймплейной логикой. Они подключаются точно так же:

lua
give Game.Combat
give Game.Inventory

local weapon = WeaponDatabase.GetWeapon("Excalibur")
print("Урон оружия:", weapon.BaseDamage)

Если какое-то пространство имён или тип не поддерживаются игрой, компилятор MLua сразу покажет понятную ошибку ещё до старта мода.
