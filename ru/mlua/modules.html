Модули и атрибуты ​

Загрузка зарегистрированного модуля ​

lua
give UnityEngine
give Mang.Reflection

Инструкция give запрашивает модуль, зарегистрированный в окружении вашего скрипта. Модуль сам определяет, какие типы и методы он предоставляет. Исходный модуль выполняется и кэшируется после успешной загрузки. При циклическом импорте или отсутствии модуля выдаётся ошибка.

Команда give UnityEngine открывает доступ к типам Unity, таким как GameObject, Transform и Vector3. Подробнее о работе с объектами Unity читайте в разделе Работа с Unity и игровым API.

Для модулей, написанных как стандартные файлы Lua, можно использовать специальную функцию require.

Для создания локального псевдонима загрузите модуль и сохраните нужный тип в локальную переменную:

lua
give UnityEngine
local Vec = UnityEngine.Vector3
local position = Vec(0, 1, 0)

Пространства имён ​

lua
namespace Game.Combat
    class Weapon
        public damage = 10
    end
end

local weapon = new Game.Combat.Weapon()

Пространство имён группирует объявления по заданному пути. Глобальные переменные чанка и импортированные значения остаются общими внутри одного скриптового окружения.

Атрибуты ​

Атрибут связывает метаданные со следующим за ним объявлением:

lua
@[Component("Spinner")]
class Spinner : MonoBehaviour
    public speed = 90
end
  • Форма записи: @[Имя] или @[Имя(аргументы)]
  • Перед одним объявлением можно указать несколько атрибутов
  • Атрибуты патчей принимают целевой метод и параметры, например owner = "my-mod"
  • Встроенные обработчики (Component, Prefix, Postfix, Replace) настраивают интеграцию с Unity и нативный перехват методов

API позволяет читать типизированные атрибуты и регистрировать собственные обработчики.

Несколько файлов ​

Файлы компилируются как отдельные чанки. Чтобы использовать объявления из другого файла, убедитесь, что этот файл был загружен или зарегистрирован как модуль до первого обращения к его типам.

Сохраняйте имена модов, чанков и пространств имён компонентов стабильными при перезагрузках, чтобы избегать конфликтов с другими модами.
