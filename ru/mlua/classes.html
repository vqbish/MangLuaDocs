Классы и интерфейсы ​

Классы позволяют объединять данные (поля) и логику (методы) в понятные и удобные типы. Интерфейсы определяют правила и контракты, которым обязаны следовать классы. Вместе они формируют полноценную объектно-ориентированную систему MLua - во время выполнения скрипта всё это быстро работает поверх таблиц и userdata, а ошибки типов отлавливаются компилятором ещё до запуска игры.

Если вы раньше программировали на C#, Java или TypeScript, синтаксис покажется вам очень знакомым. Главные отличия: ключевое слово self пишется явно в каждом методе, а вызовы родительских методов используют функцию super.

Объявление класса ​

Вот простой пример класса счётчика:

lua
class Counter
    public value: number = 0

    public function Increment(): number
        self.value = self.value + 1
        return self.value
    end
end

Объявление класса создаёт новый именованный тип. Его можно объявить глобально или внутри пространства имён (namespace). Тело класса закрывается ключевым словом end. Внутри любого метода self указывает на текущий объект.

Члены класса ​

Класс может содержать поля, методы, конструкторы и статические переменные в любых нужных вам сочетаниях:

Член классаПример синтаксисаЧто делает
Полеpublic value: number = 0Переменная экземпляра, создаётся вместе с объектом
Методpublic function Name(args): ReturnType ... endФункция, вызываемая у объекта через двоеточие: obj:Name()
Конструкторpublic function init(args) ... endИнициализирует объект при создании
Статическое полеpublic static count: number = 0Принадлежит самому классу: Counter.count
Статический методpublic static function Create(): Counter ... endВызывается напрямую у класса: Counter.Create()

Модификаторы доступа ​

У каждого поля и метода есть уровень видимости, который помогает писать надёжный код без случайных багов:

МодификаторКому доступен член класса
publicДоступен отовсюду (используется по умолчанию, если не указан)
protectedДоступен только внутри объявившего класса и всех его наследников
privateДоступен строго внутри объявившего класса

Наследование ​

Класс наследует базовый класс через двоеточие : BaseName:

lua
class Base
    public virtual function Value(): number
        return 1
    end
end

class Child : Base
    public override function Value(): number
        return super(self, Child, "Value") + 1
    end
end

Ключевые слова наследования:

Ключевое словоЧто означает
overrideОбязательно при замене унаследованного метода родительского класса
finalЗапрещает дочерним классам переопределять этот метод
abstractОбъявляет сигнатуру метода без тела - наследники обязаны его реализовать
abstract classПомечает класс, который нельзя напрямую создать через new

Чтобы вызвать реализацию метода из родительского класса, используйте super(self, ТекущийКласс, "ИмяМетода", аргументы...).

Абстрактные классы ​

Абстрактный класс служит шаблоном для создания других классов:

lua
abstract class Shape
    public abstract function Area(): number
end

class Circle : Shape
    public radius: number = 1

    public override function Area(): number
        return 3.14159 * self.radius * self.radius
    end
end

Создание объектов ​

В MLua есть три взаимозаменяемых способа создать объект и вызвать его конструктор init:

lua
local a = Counter.new()   -- строчный вызов .new()
local b = Counter.New()   -- заглавный вызов .New()
local c = new Counter()   -- привычное ключевое слово new, как в C# или Java

Все переданные аргументы автоматически направляются в метод init:

lua
class Person
    private name: string = ""

    public function init(name: string)
        self.name = name
    end

    public function GetName(): string
        return self.name
    end
end

local person = new Person("PlayerOne")
print(person:GetName()) -- "PlayerOne"

Если у класса нет явного метода init, объект создаётся со всеми полями, заполненными значениями по умолчанию.

Интерфейсы ​

Интерфейс задаёт контракт из методов, которые обязан предоставить реализующий его класс. Интерфейсы не хранят состояния - в них нет полей и готового кода.

Краткая форма - удобна, когда нужно просто перечислить имена методов:

lua
interface IValue(Value)
interface IDrink(MakeDrink, Refill)

Блочная форма - позволяет точно указать типы аргументов и возврата:

lua
interface IShape
    public function Area(): number
    public function Scale(factor: number)
end

Реализация интерфейса выполняется через ключевое слово implements:

lua
class CoffeeCup : Person
    implements IDrink
    public function MakeDrink(): string
        return "espresso"
    end

    public function Refill()
        print("Чашка наполнена!")
    end
end

Класс может реализовывать сколько угодно интерфейсов через запятую: implements IDrink, IValue, IShape. Если вы забудете написать какой-то из объявленных методов, компилятор сразу же сообщит об ошибке.

Практический пример ​

Вот как абстрактные классы и интерфейсы работают вместе в реальном коде:

lua
abstract class Entity implements IShape
    public abstract function Area(): number
    public name: string = "entity"
end

class Box : Entity
    public width: number = 1
    public height: number = 1

    public override function Area(): number
        return self.width * self.height
    end
end

local box = new Box()
box.width = 4
box.height = 3
print("Площадь:", box:Area()) -- 12
