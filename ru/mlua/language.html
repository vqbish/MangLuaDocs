Справочник языка MLua ​

MLua является строгим надмножеством Lua 5.4, поэтому любой корректный скрипт на Lua 5.4 работает в MLua без каких-либо изменений. Всё стандартное поведение Lua сохранено: комментарии, строки, числа, операторы, управляющие конструкции, замыкания, vararg, множественный возврат, метатаблицы, корутины и goto. Все описанные на этой странице возможности либо напрямую унаследованы из Lua, либо являются чистыми расширениями MLua.

Это руководство предполагает знакомство хотя бы с одним статически типизированным языком (C#, TypeScript или Java). Специфичные для Lua концепции вроде метатаблиц здесь не рассматриваются - подробности можно найти в справочном руководстве Lua.

Чанки ​

Чанк (chunk) - это последовательность инструкций. Точки с запятой между инструкциями не требуются, но одиночный символ ; принимается как пустая инструкция.

lua
local message = "hello"
print(message)

Комментарии ​

Однострочные и многострочные комментарии соответствуют стандартному синтаксису Lua:

lua
-- Однострочный комментарий

--[[ Многострочный комментарий,
     занимающий несколько строк ]]

Значения и типы данных ​

MLua использует те же восемь базовых типов значений, что и Lua:

ТипОписание
nilОтсутствие значения
booleantrue или false
numberЧисло (целое или с плавающей точкой)
stringНеизменяемая последовательность байт
tableАссоциативный массив, основа для всех объектов
functionФункция как объект первого класса
userdataОбъект, управляемый хостом (например, компонент Unity)
threadКорутина

MLua не вводит новых рантайм-типов. Классы, интерфейсы и перечисления представляют собой слой времени компиляции поверх таблиц и userdata.

Переменные ​

Локальные, глобальные, константные и закрываемые переменные следуют синтаксису Lua 5.4:

lua
local count = 0
local a, b, c = 1, 2       -- c равен nil
local frozen <const> = 10  -- константа времени компиляции
local handle <close> = open() -- автоматически закрывается при выходе из области видимости
globalValue = 1             -- глобальное присваивание

Любая локальная переменная может содержать аннотацию типа. Компилятор проверяет её перед запуском скрипта:

lua
local speed: number = 90
local owner: Player = FindPlayer()

→ Подробнее о системе типов, выводе и совместимости читайте в разделе Типы и аннотации.

Операторы ​

MLua сохраняет все операторы Lua 5.4 и добавляет запросы типов и безопасный доступ:

ГруппаОператоры
Арифметика+ - * / // % ^ унарный -
Побитовые& | ~ << >> унарный ~
Сравнение== ~= < <= > >=
Логикаand or not
Строка / размер.. #
Проверка типовinstanceof(v, C) implements(v, I) typeof(v) kindof(v) classof(v)
Безопасный доступ?. ??

Поддерживаются составные присваивания (+=, -=, *= и другие).

lua
local label = enemy?.name ?? "unknown" -- безопасный доступ с fallback-значением
local isEnemy = instanceof(value, Enemy)  -- проверка типа в рантайме
local typeName = typeof(value)           -- имя типа в виде строки

Управление потоком выполнения ​

В MLua доступны все управляющие конструкции Lua 5.4, а также ключевое слово continue для перехода к следующей итерации цикла:

lua
-- Условие
if value > 10 then
    print("high")
elseif value > 0 then
    print("low")
else
    print("zero")
end

-- Цикл while
while active do
    step()
end

-- Цикл repeat-until
repeat
    step()
until done

-- Числовой цикл for с continue
for index = 1, 10, 2 do
    if index == 5 then continue end
    print(index)
end

-- Обобщённый for
for key, value in pairs(source) do
    print(key, value)
end

-- Явная область видимости
do
    local scoped = 1
end

Управление циклами:

ИнструкцияПоведение
breakПрерывает выполнение текущего цикла
continueПереходит к следующей итерации (только в MLua)
goto label / ::label::Безусловный переход, как в Lua 5.4

Функции ​

Функции являются значениями первого класса:

lua
-- Локальная именованная функция
local function add(a, b)
    return a + b
end

-- Глобальная функция с varargs
function Global(a, ...)
    return a, select("#", ...)
end

-- Функциональное выражение
local handler = function(event) end

-- Метод с неявным self
local target = {}
function target:Method(value)
    return self, value
end

Параметры и возвращаемые значения поддерживают аннотации типов:

lua
local function Distance(from: Vector3, to: Vector3): number
    return (to - from).magnitude
end
