Директивы препроцессора и условная компиляция ​

Директивы препроцессора вычисляются MLua ещё до компиляции скрипта. С их помощью можно легко включать и выключать отдельные функции мода, поддерживать разные версии игры или отделять отладочный код от релизного.

Объявление значений ​

Вы можете объявлять флаги прямо в начале файлов с помощью директивы #define:

lua
#define SHOW_COUNTER true
#define LIMIT 10
#define MOD_NAME "ExampleMod"

#ifdef SHOW_COUNTER
print("Счётчик включён!")
#endif

Директива #define NAME сама по себе задаёт значение true. Также можно указывать логические значения, числа или строки в двойных кавычках. Имена директив чувствительны к регистру.

Доступные директивы ​

ДирективаЧто делает
#define NAME valueЗадаёт флаг или значение в текущей ветке
#undef NAMEУдаляет ранее объявленный флаг
#ifdef NAMEПроверяет, был ли объявлен флаг
#ifndef NAMEПроверяет, что флаг не объявлен
#if NAMEПроверяет истинность значения флага
#ifnot NAMEПроверяет ложность значения флага
#elif NAME, #elseif NAMEАльтернативное условие
#elseВетка по умолчанию, если условия выше ложны
#endif, #endЗакрывает условный блок

Условия принимают имя флага, перед которым может стоять знак ! или not. Это инструмент условного включения кода - сложные арифметические выражения вроде #if VERSION >= 2 не поддерживаются.

lua
#define FEATURE false

#ifdef FEATURE
print("FEATURE объявлена")
#endif

#if FEATURE
print("Эта строка не попадет в скомпилированный код")
#else
print("FEATURE выключена")
#endif

#undef FEATURE

Неактивные строки в коде заменяются пустыми строками, благодаря чему номера строк в ошибках компилятора всегда точно совпадают с вашим файлом.

Флаги, передаваемые игрой ​

Игра может передавать глобальные флаги в окружение модов через таблицу DEFINE. Проверить их наличие можно с помощью функции defined(name):

lua
if defined("GAME_VERSION") then
    print("Версия игры:", DEFINE["GAME_VERSION"])
end
